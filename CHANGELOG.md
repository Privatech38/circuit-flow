# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Property editor for circuit components

## [0.2.0] - 2026-09-14

### Added

- Target handle ID in evaluation function
- SR Latch
- D, T, and JK Flip-Flops
- InputCircuitComponent type

### Changed

- Updated component tree styling
- Replace evaluation time input reading to a trigger time snapshot system
- Improved app CSS

## [0.1.0] - 2026-09-10

### Added

- Functioning toolbar
- Circuit flow simulation with live visualization
- Basic circuit components (clock, high, low, logic gates, light, multiplexer)
